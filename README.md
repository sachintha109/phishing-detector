# Phishing Detection System

## Overview
This project is a real-time phishing URL detection system developed using Python Flask and VirusTotal API.

The system analyzes URLs and classifies them as:
- Safe
- Suspicious
- Phishing

It also generates a risk score based on malicious detections.

---

## Features
- Real-time URL scanning
- VirusTotal API integration
- Risk score calculation
- Safe / Suspicious / Phishing detection
- Professional user interface
- Scan timestamp display

---

## Technologies Used
- Python
- Flask
- HTML/CSS
- VirusTotal API

---

## How to Run

1. Install requirements

```bash
pip install -r requirements.txt
```

2. Run application

```bash
py app.py
```

3. Open browser

http://127.0.0.1:5000
